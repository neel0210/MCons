Core Features

Engineered with macOS DNA

MCons doesn't just paint folders — it creates high-density custom icon families conforming to macOS Sonoma & Sequoia design specifications.

⚡

1-Click Drag & Drop

Drop any folder onto MCons and select an icon. Writes directly to macOS extended attributes (`com.apple.ResourceFork` / `Icon\r`), updating Finder and Dock instantly.

🛠️

Custom Pack Builder

Import any SVG, PNG, or vector artwork. MCons automatically cuts out the silhouette, adjusts lighting, and frames it with native macOS folder geometry.

🚀

Lightning Batch Apply

Organize dozens of client projects or dev repositories in seconds. Select multiple directories and apply matched icons and colors with recursive depth and full undo.

🧭

Menu Bar Companion

Tucked neatly into your top macOS status bar for rapid drag-and-drop icon application without ever switching away from Finder or your code editor.

🔒

100% Non-Destructive

Zero SIP disabling required. MCons respects macOS Gatekeeper and security boundaries. Click "Restore Default" and your folder returns to original blue instantly.

🔄

Sparkle Auto-Updates

Integrated with Sparkle 2 framework. New icon packs, system optimizations, and macOS version compatibility patches arrive seamlessly with signed Delta updates.

Downloading MCons.dmg

Follow these 3 simple installer steps on macOS:

1
Open Disk Image

Double-click the downloaded MCons.dmg in your Downloads folder to open it.

2
Drag into Applications

Drag the MCons.app icon into the Applications shortcut folder inside the disk image.

3
First Launch (macOS Gatekeeper)

Because MCons is downloaded outside the Mac App Store, choose either method to unlock:

  • Fast: Double-click Open_MCons.command inside the DMG.
  • Standard: Right-click MCons.app in Applications → click Open.
  • Terminal: Click the command below to copy and run:
xattr -cr /Applications/MCons.app 📋
